# 本轮 Closeout Schema

## 交付字段

1. `变更`：每个修改文件与面向产品的变化。
2. `证据判定`：已接纳、已撤下、待补的截图及理由。
3. `验证`：静态资源、JavaScript 解析、HTTP、视觉/浏览器检查的命令与结果；浏览器不可用必须如实写明。
4. `四条对抗式审查 lane`：Claude、Codex、Grok、Antigravity 各自的状态、证据路径、是否 binding。
5. `Non-claims`：本轮没有证明的事项。
6. `PRD Map Summary`：用产品语言说明本轮提升、下一步与可复制提示词。

## 退出标准

只有当上述字段均有真实证据或明确的失败/阻塞状态时，才能声明本轮完成；任何无法控制的浏览器或 reviewer 通道都不得写为通过。
